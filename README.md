# Livraria · Controle de empréstimos

Aplicação ASP.NET Core MVC para cadastrar clientes e livros e controlar empréstimos em SQL Server.

Use a versão do SDK indicada no projeto. Configure `LIVRARIA_CONNECTION_STRING` para um banco SQL Server local de teste e execute `dotnet run --project LivrariaControleEmprestimo.WEB`. Em ambiente de desenvolvimento o EF Core inicializa o esquema no banco local de demonstração.
